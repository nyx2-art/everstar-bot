# Everstar Bot

Instant Trade only version for Deriv Volatility indices.

- Autopilot removed
- Higher quality Instant Trade filter (score ≥ 64)
- Persistent trade history
- Dark night desk UI

## Deploy

This project is ready for Vercel.

1. Import the repository on [vercel.com](https://vercel.com)
2. Deploy with default settings
3. Open the permanent URL Vercel gives you
